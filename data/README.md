# Dataset notice

`historical_prices.csv` is illustrative sample data generated for this project, spanning eight crops, five named markets, and weekly dates from 2025-09-28 through 2026-09-27. It is not collected from farmers, a government source, or a live market feed. Replace it with a verified dataset before using forecasts to make real selling decisions. The market price patterns are synthetic, for demonstrating the application flow only.
